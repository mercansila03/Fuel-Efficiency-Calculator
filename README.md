# Fuel Efficiency (MPG) Calculator in Python

A sentinel-controlled Python program designed to help drivers track their vehicle's fuel efficiency across multiple fuel-ups. 

## Features
- Dynamically accepts fuel used (gallons) and distance traveled (miles) for each trip.
- Uses a sentinel value (`-1`) to end data entry, allowing an unknown number of trips to be recorded.
- Calculates miles-per-gallon (MPG) for each individual tank.
- Computes the overall average MPG across all recorded trips.
- Formats all numerical outputs to exactly 6 decimal places.
